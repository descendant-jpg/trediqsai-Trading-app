Let's build a fully functional `NotificationSettingsScreen.tsx`. This needs to be a highly detailed, scrollable settings page that persists user preferences using `AsyncStorage` and can fire local notifications using `expo-notifications`.

### 1. Setup & State Management
- Install `expo-notifications` and `@react-native-async-storage/async-storage` if not already installed.
- Setup `useEffect` to request notification permissions on mount and load saved settings from `AsyncStorage`.
- State variables needed (save to AsyncStorage every time they change): 
  - `masterPush` (boolean)
  - `soundMode` ('Default' | 'Silent')
  - `selectedPairs` (array of strings, default to all pairs selected)
  - `marketAlerts` (boolean)
  - `calendarIcon` (boolean)

### 2. UI Layout & Theming
- Background: #0A0B0E. 
- Use a `ScrollView` with standard React Native `SafeAreaView`.
- Section Headers: Small, bold, white text with top margin.
- Cards: Background #16181D, rounded corners, subtle borders (#22252A).
